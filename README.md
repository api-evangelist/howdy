# Howdy

Howdy is a nearshore talent platform and employer of record (EOR) that connects US companies with senior software engineers, data, DevOps, design, and product professionals across Latin America. It handles recruiting, vetting, payroll, benefits, equipment, compliance, and team performance coaching. Founded in 2018 in Austin, Texas by Jacqueline Samira and Frank Licea; Y Combinator W21.

Howdy is a services/staffing business and does not publish a public developer API. This API Evangelist profile captures its public web, agent-facing (`/for-ai`), legal, and domain-security surface.
